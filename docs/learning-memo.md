# 学習メモ

## 1. このファイルの目的

プロフィールサイトの制作を通じて学んだことを記録する。
コードを見返したときに、それぞれのファイルや技術が何のためにあるのかを理解できるようにする。

## 2. 使用している技術

### Next.js

- **役割：** ReactをベースにWebサイトを構築するためのフレームワーク。
- **このプロジェクトでの使い方：** ページの表示や、サイト全体の構成に使用している。

### React

- **役割：** UI（画面の見た目や操作部分）をコンポーネント単位で作るためのライブラリ。
- **このプロジェクトでの使い方：** プロフィールや経歴、スキルなどの画面を構成している。

### TypeScript

- **役割：** JavaScriptに型の仕組みを追加した言語。
- **メリット：** データの型の間違いなどを、開発中に発見しやすくなる。

### Tailwind CSS

- **役割：** 用意されたクラス名を使って、HTML要素の見た目を調整するCSSフレームワーク。
- **このプロジェクトでの使い方：** 文字の大きさ、余白、色、画面幅に応じたレイアウトなどを指定している。

## 3. 主なファイルの役割

### `app/page.tsx`

- トップページの内容を定義するファイル。
- プロフィールサイトに表示する文章や各セクションの構成を記述する。

### `app/layout.tsx`

- ページ全体で共通するレイアウトや設定を定義するファイル。
- ページタイトルなどのメタデータや、HTMLの基本設定を管理する。

### `app/globals.css`

- サイト全体に適用するCSSを記述するファイル。
- Tailwind CSSの読み込みや、共通のスタイル設定に使用する。

### `package.json`

- プロジェクトで使用するパッケージや、実行できるコマンドを管理するファイル。
- 例：`npm run dev` で開発用サーバーを起動する。

## 4. 開発・確認で使ったコマンド

| コマンド | 役割 |
|---|---|
| `npm run dev` | 開発用サーバーを起動する |
| `npm run build` | 本番公開に向けてビルドする |
| `npm run start` | ビルド済みのサイトを起動する |
| `ls` | ファイルやフォルダの一覧を表示する |
| `mkdir docs` | `docs` フォルダを作成する |
| `touch docs/learning-memo.md` | 学習メモのファイルを作成する |

## 5. 今回の動作確認で学んだこと

- `npm run build` が成功すると、本番向けのビルドが正常に完了したことを確認できる。
- ブラウザのデベロッパーツールを使うと、スマートフォン程度の画面幅で表示を確認できる。
- ページ内リンクをクリックして、対応するセクションへ移動できるか確認できる。
- PageSpeed Insightsを使って、公開サイトのパフォーマンスなどを測定できる。
- ブラウザのエラーが出た場合は、すぐにコードを変更せず、原因を切り分けることが大切。

## 6. 今後、理解を深めたいこと

- `app/page.tsx` のコードが、どのように画面表示につながるのか。
- TypeScriptの型が、データの管理にどう役立つのか。
- Tailwind CSSのクラス名が、どのCSSの指定に対応するのか。
- GitのコミットやGitHubへのプッシュが、制作履歴の管理にどう役立つのか。
