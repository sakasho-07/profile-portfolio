# SHO SAKAMOTO Profile Portfolio

SHO SAKAMOTOのプロフィールポートフォリオサイトです。

化学メーカーでの研究開発職、オーストラリアでの約2年間のワーキングホリデーを経て、現在AIとプログラミングを学びながらWeb制作に取り組んでいる経歴や学習内容を紹介しています。

**公開URL：** https://profile-portfolio-tan.vercel.app/

## 主なセクション

| セクション | 内容 |
| --- | --- |
| About（自己紹介） | これまでの歩みと、Web制作に取り組む想い |
| Career（経歴） | 大学院修了から現在までをタイムライン形式で紹介 |
| Skills（スキル） | 「このサイトで使用」「学習中」「学び方」の3グループで紹介 |
| Works（制作実績） | 制作中・準備中・計画中のステータス付きで作品を紹介 |

## 使用技術

- [Next.js](https://nextjs.org) 16.4.2（App Router）
- React 19.3.0
- TypeScript 5
- Tailwind CSS 4（`@tailwindcss/turbopack` で読み込み）
- ESLint 9（`eslint-config-next`）
- `next/font`（Geist / Geist Mono）
- Vercel（ホスティング）

## 実装済みの特徴

- **レスポンシブ対応**：Tailwind CSSのブレークポイントで、スマートフォンからPCまでレイアウトや文字サイズを調整
- **ライトモード・ダークモード対応**：OSの設定（`prefers-color-scheme`）に合わせて配色を自動で切り替え
- **配色の一元管理**：CSS変数（カスタムプロパティ）を使用し、背景・文字・カード・アクセントカラーなどをまとめて管理
- **Tailwind CSSとの連携**：`@theme inline` を使用してCSS変数をTailwind CSSのカラーユーティリティとして利用
- **SEO設定**：Metadata APIでタイトル・ディスクリプション・OGP（`og:title` / `og:description` / `og:site_name` / `og:locale` など）を設定し、`<html lang="ja">` を指定
- **アクセシビリティへの配慮**：セマンティックなHTML構造、`aria-labelledby` によるセクション見出しの関連付け、キーボード操作時のフォーカス表示
- **ページ内ナビゲーション**：ヘッダーから各セクションへアンカーリンクで移動
- **データとUIの分離**：経歴・スキル・制作実績は配列データで管理し、項目の追加・更新がしやすい構成

## 追加改善：配色・デザインの調整

サイト全体の印象を明るく柔らかい雰囲気にするため、背景色や文字色、カード、ボタンなどの配色を見直しました。

### 主な変更内容

| 対象 | 採用した色 |
| --- | --- |
| メイン背景 | `#F7F8F5`（淡いオフホワイト） |
| カード背景 | `#FFFFFF`（ホワイト） |
| アクセントカラー | `#DCEAE4`（淡いブルーグリーン） |
| メイン文字色 | `#26352F`（深いグレーグリーン） |
| 補助文字色 | `#4A5C54` / `#5D6E66` |
| 境界線 | `#E3E7E2` / `#C3CDC7` |

### 技術的な改善ポイント

- CSS変数（カスタムプロパティ）を利用し、色の定義を `app/globals.css` に集約
- `:root` でライトモードの配色を定義
- `@media (prefers-color-scheme: dark)` でダークモード用の配色を定義
- `@theme inline` でCSS変数をTailwind CSSのテーマに登録
- `bg-primary`、`bg-accent`、`text-foreground` などの共通クラスを使用して配色を統一
- 制作実績のステータス表示やリンクのホバー時・フォーカス時の色合いを調整

### 改善時に意識したこと

- 背景色だけでなく、文字・カード・ボタン・境界線など全体の色のバランスを整える
- 明るい背景でも文字が読みやすいコントラストを確保する
- ライトモードとダークモードの両方で統一感を持たせる
- CSS変数を活用し、今後の配色変更やメンテナンスをしやすくする

## 今回の改善で学んだこと

- Webサイトの配色は、背景色だけでなく文字・カード・ボタン・境界線など全体のバランスが重要であること
- CSS変数を使用することで、サイト全体の色を一元管理できること
- Tailwind CSSとCSS変数を組み合わせることで、デザインの統一性と変更のしやすさを両立できること
- ライトモードとダークモードでは、同じデザイン要素でも適切な色を個別に設定する必要があること
- 既存のレイアウトや機能を維持しながら、デザインを改善する考え方
